# Fase 1 — Base: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pasar pokeWeb de SPA Vite + Firebase a un monorepo con Next.js (App Router), Supabase (cuentas y favoritos) y el esqueleto del servidor de batallas, todo en TypeScript estricto y con CI.

**Architecture:** pnpm workspaces con `apps/web` (Next.js en Vercel), `apps/battle-server` (Node + `ws` en Railway) y `packages/shared` (validaciones y protocolo). La web lee PokeAPI solo desde el servidor a través de `lib/pokeapi.ts`; la sesión vive en cookies con `@supabase/ssr`; el servidor de batallas valida el JWT de Supabase contra su JWKS.

**Tech Stack:** Next.js (última estable) + React 19, TypeScript estricto, Tailwind 3, framer-motion, react-three-fiber 9 / drei 10, chart.js, sonner, Supabase (`@supabase/ssr`, `@supabase/supabase-js`), `ws`, `jose`, Vitest, Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-12-fase-1-base-design.md`

## Global Constraints

- TypeScript `strict: true` en los tres paquetes; ningún `.js`/`.jsx` de aplicación; no se usa `any`.
- El sitio se ve y se comporta igual que hoy: se conservan clases de Tailwind, `index.css`, animaciones y escenas 3D. Nada de rediseño.
- Interfaz en español; todos los textos visibles viven en `apps/web/lib/strings.ts`.
- Los componentes nunca llaman a PokeAPI: solo `apps/web/lib/pokeapi.ts`, con `fetch` y `next: { revalidate: 86400 }`.
- Firebase, MUI, Emotion, jQuery, Redux, react-router, axios, lodash y Storybook no aparecen en dependencias ni imports.
- Nombre de usuario: 3–20 caracteres, solo letras, números y guion bajo (`/^[A-Za-z0-9_]{3,20}$/`).
- Ningún secreto en el repo; variables documentadas en `.env.example` de cada app.
- Commits sin líneas `Co-Authored-By` (ver `CLAUDE.md`).
- Node 22, pnpm 10.

## Review Focus

1. `/pokemon/[id]` con un id o nombre inexistente (`/pokemon/zzz`, `/pokemon/999999`) → página 404, no error 500. (Tarea 3 y 4)
2. Búsqueda en la Pokédex con mayúsculas, espacios alrededor o vacía (`" Pikachu "`, `""`) → normaliza y encuentra; vacía no hace petición. (Tarea 3)
3. PokeAPI responde 5xx o no responde → `PokeApiError`, y la ruta muestra la pantalla de error con botón de reintento. (Tarea 3 y 4)
4. Añadir dos veces el mismo favorito (doble clic) → una sola fila, sin error visible. (Tarea 7)
5. WebSocket con JWT caducado o firmado con otra clave → cierre con código 4401. (Tarea 8)
